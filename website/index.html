Toolchains

Five Node versions. One of them reached end of life.

Disk Cleaner finds the runtimes you installed through Homebrew, nvm, fnm, Volta, pyenv, rbenv, asdf and rustup, and grades each one against its official release schedule.

  • Rates each one update now, soon or when convenient — and says why.
  • Gives you the exact command for your install method. You run it; nothing changes behind your back.
  • Works offline until you press Check Online. Your versions are never sent.

Security & network

The audit you'd run by hand — in one click.

Years of SDKs, installers and helper tools leave background code behind. Disk Cleaner reads what macOS starts at login and what's listening on your network, and explains each finding in plain words.

  • System protections — SIP, Gatekeeper, FileVault, device management.
  • Launch agents & daemons — unsigned code, programs that no longer exist, anything that runs from a folder anyone can write to.
  • Network — firewall and stealth mode, Screen Sharing, SMB, AirPlay, proxies, and Postgres, Redis, MongoDB or a dev server exposed beyond localhost.

Built not to break things

Confident, because it's careful.

  • Trash, never rm.

    Everything you clean goes to the Trash, so you can put it back.

  • Preview first.

    Every item and its size, before anything moves. Only items that rebuild themselves are preselected.

  • Personal folders stay out of reach.

    Documents, Desktop, iCloud, Mail, Messages and Keychains are never cleaned automatically; cloud folders are never even read.

  • No shell, no surprises.

    simctl and docker run from a fixed allowlist with validated arguments. Fixes that need admin rights are shown as a command you run yourself.

  • Local by default.

    No account. No network access unless you press Check Online or opt in to anonymous statistics. See exactly what's sent

  • Native and light.

    A 6 MB SwiftUI app for Apple silicon and Intel. Signed with a Developer ID and notarized by Apple.
